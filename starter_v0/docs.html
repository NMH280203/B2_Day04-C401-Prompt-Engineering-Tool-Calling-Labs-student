Kiến trúc

Cách hoạt động

Mỗi tin nhắn từ user đi qua 4 bước xử lý trước khi trả kết quả.

1
User Message
User gửi câu hỏi bằng tiếng Việt hoặc tiếng Anh
2
LLM Router
Model đọc system prompt + tool descriptions để chọn đúng tool và điền args
3
Tool Execution
Tool được gọi thực sự (API call, SMTP, ...) và trả về kết quả JSON
4
Final Response
Model tổng hợp kết quả tool và trả lời user bằng ngôn ngữ tự nhiên
11 Tools

Danh sách Tool

Mỗi tool có vai trò riêng biệt. Agent chọn đúng tool dựa trên context của câu hỏi.

🐦
timeline
Read

Lấy tweet gần đây từ timeline của một người cụ thể trên Twitter/X. Cần biết handle (@username).

Parameters
screenname string Handle Twitter (e.g. sama, elonmusk) required
limit integer Số tweet cần lấy, mặc định 5 optional
Khi nào: Hỏi tweet của một người cụ thể (Sam Altman, Elon Musk…)
🔍
social_search
Search

Tìm kiếm tweet theo chủ đề hoặc từ khóa — không phải của một người cụ thể.

Parameters
query string Từ khóa tìm kiếm required
search_type string Latest (mặc định) hoặc Top (phổ biến nhất)
limit integer Số kết quả, mặc định 5
Khi nào: "Mọi người đang bàn gì về GPT-5?"
🌐
lookup
Search

Tìm kiếm web khi không có URL cụ thể. Hỗ trợ lọc theo tin tức và thời gian.

Parameters
query string Từ khóa cốt lõi (không chứa "tin tức") required
topic string news | general
timeframe string day | week | month | year
Khi nào: "Tin tức AI hôm nay" → query="AI", topic=news, timeframe=day
📄
fetch
Read

Đọc toàn bộ nội dung của một URL cụ thể mà user đã cung cấp.

Parameters
url string URL đầy đủ (https://...) required
Khi nào: "Tóm tắt bài này: https://openai.com/blog/gpt-5"
❓
clarify
Meta

Hỏi lại user khi thiếu thông tin quan trọng, hoặc để xác nhận trước khi thực hiện hành động ghi.

Parameters
question string Câu hỏi required
response_type string text | yes_no | choice
Khi nào: Thiếu handle, URL, hoặc trước khi gửi/publish
📋
format
Format

Trình bày dữ liệu đã thu thập thành bản tin, digest hoặc thread đẹp.

Parameters
items array Danh sách item đã thu thập required
template string brief | sections | bullets | thread | daily_ai_vn required
Khi nào: Sau khi có data, render thành bản tin đẹp
📤
send
Write ⚠️

Gửi văn bản lên Telegram. Luôn yêu cầu xác nhận (yes_no) trước khi gọi.

Parameters
text string Nội dung cần gửi required
confirmed boolean Phải là true sau khi user xác nhận
Flow: clarify(yes_no) → user OK → send(confirmed=true)
✉️
send_email
Write ⚠️

Gửi email qua SMTP (Gmail mặc định). Luôn xác nhận trước khi gửi, không hỏi về CC nếu user không nhắc.

Parameters
to string Email người nhận required
subject string Tiêu đề required
body string Nội dung required
cc string CC (optional, chỉ hỏi nếu user đề cập)
confirmed boolean true sau khi user xác nhận
Cần: EMAIL_SENDER + EMAIL_PASSWORD trong .env
📜
policy
Read

Tra cứu tài liệu chính sách nội bộ công ty — không tìm trên internet.

Parameters
query string Nội dung cần tra cứu required
policy_area string all | ai_research | source_citation | data_privacy | external_publishing | tool_usage
Khi nào: "Chính sách trích dẫn nguồn của công ty?"
📚
papers
Search

Tìm kiếm bài báo khoa học trên arXiv theo chủ đề hoặc từ khóa.

Parameters
query string Từ khóa học thuật required
max_results integer Số bài tối đa, mặc định 5
sort_by string relevance | lastUpdatedDate | submittedDate
Khi nào: "Tìm paper về diffusion models" → dùng papers, không dùng lookup
📖
paper_text
Read

Đọc toàn bộ nội dung text của một bài báo arXiv cụ thể theo ID hoặc URL.

Parameters
arxiv_url string arXiv ID hoặc URL đầy đủ required
max_pages integer Số trang tối đa, mặc định 5
max_chars integer Ký tự tối đa trả về, mặc định 8000
Khi nào: Dùng sau papers để đọc chi tiết một bài cụ thể
Routing Logic

Chọn Tool Nào?

Agent sử dụng các quy tắc này để chọn đúng tool cho từng câu hỏi.

Câu hỏi ví dụTool được chọnArgs chínhLý do
"Tweet mới nhất của Sam Altman?" timeline screenname="sama" Hỏi về 1 người cụ thể → map tên → handle
"Mọi người bàn gì về GPT-5?" social_search query="GPT-5" Chủ đề/topic trên Twitter, không phải 1 người
"Tin tức AI hôm nay?" lookup query="AI" topic="news" timeframe="day" Web news, "hôm nay" → timeframe=day
"Tóm tắt bài https://openai.com/..." fetch url="https://..." Đã có URL cụ thể → đọc trực tiếp
"Tóm tắt 5 tweet giúp mình" (không có tên) clarify response_type="text" Thiếu thông tin ai → hỏi, không đoán
"Đăng bản tin này lên Telegram" clarify response_type="yes_no" Write action → xác nhận trước khi gửi
"Tìm paper về RAG" papers query="RAG" Bài báo khoa học → arXiv, không phải web
"Tìm tin web AI và tìm tweet về AI" lookup + social_search parallel Hai nguồn độc lập → gọi song song
"Viết code Python tính Fibonacci" — (no tool) — Ngoài phạm vi research → từ chối lịch sự
"Chính sách trích dẫn nguồn?" policy policy_area="source_citation" Quy định nội bộ → policy, không tìm web

Safety Boundaries

Những gì Agent làm và không làm

Agent có ranh giới rõ ràng để đảm bảo an toàn và chính xác.

✅ Agent SẼ làm

🐦Lấy tweet của người nổi tiếng theo tên
🌐Tìm tin tức web với đúng timeframe
📄Đọc URL cụ thể người dùng cung cấp
📚Tìm bài báo khoa học trên arXiv
❓Hỏi lại khi thiếu thông tin quan trọng
🔄Gọi song song nhiều tool khi cần
📜Tra cứu chính sách nội bộ
✉️Gửi email sau khi xác nhận

❌ Agent KHÔNG làm

🚫Tự đoán handle khi user không nêu tên ai
🚫Tự gửi email/Telegram mà không hỏi xác nhận
🚫Viết code Python, giải toán, văn sáng tạo
🚫Dùng lookup khi đã có URL cụ thể
🚫Dùng timeline cho tìm kiếm theo chủ đề
🚫Hỏi CC email khi user không đề cập
🚫Gọi tool khi user hỏi về bản thân agent
🚫Dùng lookup thay cho papers khi hỏi về research

Hướng Dẫn

Cách Chạy

Thiết lập và chạy Research Agent trong vài phút.

1

Cấu hình .env

Điền API keys vào file .env (sao chép từ .env.example):

OPENROUTER_API_KEY=sk-or-v1-...
TAVILY_API_KEY=tvly-...
RAPIDAPI_KEY=your-key
# Email (optional)
EMAIL_SENDER=your@gmail.com
EMAIL_PASSWORD=xxxx xxxx xxxx xxxx
2

Chạy Web UI (khuyến nghị)

Giao diện web đẹp tại http://localhost:5000:

python web_ui.py --provider openrouter --version v0
3

Chạy Chat CLI

Chat trực tiếp trong terminal:

python chat.py --provider openrouter --version v0
4

Chạy Evaluation

Đánh giá độ chính xác trên bộ test case:

# Base eval (20 cases)
python run_eval.py --provider openrouter --version v3 --suite base --eval-cases data/eval_base.json

# Group eval (5 cases tự viết)
python run_eval.py --provider openrouter --version v3 --suite group --eval-cases data/eval_group.json
